# Game of Life

Классическая игра «Жизнь» Конвея на C++ + SDL2.

## Управление

| Клавиша | Действие |
|---------|----------|
| `ESC` | Выход |
| `SPACE` | Очистить поле |
| `A` | Режим: малый корабль |
| `B` | Режим: большой корабль |
| `S` | Режим: выстрел |
| `ЛКМ` | Разместить / выстрелить |

## Сборка

```bash
# Установить SDL2
sudo apt-get install libsdl2-dev   # Linux
brew install sdl2                   # macOS

# Собрать
g++ main.cpp life.cpp -o life -lSDL2
./life
